# Nis Avcisi – Privacy Policy

Last updated: 2026-11-18

Nis Avcisi is a personal command-line tool that runs only on its developer's own computer. It has no user accounts, no hosted website, no cookies and no analytics, and it does not collect personal information from anyone.

## YouTube API Services
Nis Avcisi uses YouTube API Services to read public video and channel information (titles, view counts, durations, publish dates, subscriber counts and channel creation dates). By using Nis Avcisi you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms).

Google Privacy Policy: [http://www.google.com/policies/privacy](http://www.google.com/policies/privacy)

## Storage on the device
Data obtained from YouTube API Services is stored as local files only on the developer's own computer. It is never shared with third parties and it is deleted automatically within 30 days. No cookies or similar technologies are used, and no third parties serve content or ads.

## Google account access
Nis Avcisi does not use Google account sign-in and does not access any user's account data. Any app access to a Google account can be reviewed and revoked on Google's security settings page: [https://security.google.com/settings/security/permissions](https://security.google.com/settings/security/permissions)
